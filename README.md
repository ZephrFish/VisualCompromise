# Visual Compromise
A set of python scripts for encoding files in B64 into Layers 0 and 1 of a JPEG image while not compromising the integrity of the JPEG visually.

## EncodeThatPic.py
This script essentially takes either a stream of B64 or a file and an input jpeg and encodes the file into the layers of the JPEG.

## DecodeThatPic.py
This does the reverse of the encode function.
